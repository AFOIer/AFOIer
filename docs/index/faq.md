# 常见问题

## 本站内容适合哪些人阅读？

由于大部分作者均有信息学竞赛（OI）背景，站点建立的动机也是服务信息学竞赛选手（OIer）群体，因此部分建议、经验等内容可能不适用于所有人。例如：

- 默认读者能够理解一些信息学竞赛领域的术语或常见表述
- 对于浙江省高考选考技术科目，会更偏向通用技术而非信息技术部分
- 对高校进行分析时会更多考量信息类专业的情况

当然我们也希望任何人，无论是否有信息学竞赛经历，都能从本站分享的内容中获益，也欢迎不同背景的读者参与讨论和贡献。

此外，本站可能不适用于：

- 学习信息学竞赛的某个知识点
- 学习“少儿编程”或类似内容
- 寻求一对一授课或咨询服务
- 不具备高考报名资格的外籍或港澳台籍学生
- 纯海外升学路径，且不计划参加[中国计算机学会组织和主办的信息学竞赛](https://www.noi.cn/gynoi/jj/)
